# CSE ASPIRANT – BOT COMMANDS REFERENCE

All commands support the three standard prefixes:
- `/command`
- `!command`
- `.command`

---

## 🚀 Core Bot Commands
| Command | Arguments | Description |
| :--- | :--- | :--- |
| `start` | None | Displays official bot banner (`https://i.ytimg.com/vi/9Bk5WgGfkwM/maxresdefault.jpg`) and interactive Help Menu |
| `help`, `menu` | None | Opens the interactive Help Center with 8 category buttons |

---

## 🎵 Music Commands
| Command | Arguments | Description |
| :--- | :--- | :--- |
| `play`, `p` | `<query or stream URL>` | Search and stream high-definition audio in voice chat |
| `pause` | None | Pause ongoing audio playback |
| `resume` | None | Resume paused track |
| `skip`, `next` | None | Skip current track to the next queue item |
| `prev`, `previous` | None | Play previous track from playback history |
| `stop` | None | Stop playback, leave voice chat, and clear queue |
| `queue`, `q` | None | View active playback queue and current track |
| `shuffle` | None | Randomly reorder queued tracks |
| `repeat`, `loop` | `off` / `one` / `all` | Toggle repeating current track or entire queue |
| `volume`, `vol` | `0` to `200` | Adjust streaming volume |
| `playlist` | `<playlist_name>` | Load curated playlist (`study_focus`, `coding_flow`) |
